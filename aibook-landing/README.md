# Возможности AIbook

## iPad

- Пишите и рисуйте Apple Pencil на многостраничном холсте.
- Используйте перо, карандаш, маркер, два ластика и лассо.
- Импортируйте PDF, делайте пометки и экспортируйте готовую заметку.
- Выделяйте рукописный фрагмент и задавайте вопрос ИИ.
- Ведите несколько ИИ-чатов с сохранённой историей.
- Записывайте аудио и получайте английскую расшифровку с таймкодами.
- Импортируйте записи из Files и Voice Memos.
- Открывайте дополнительную заметку рядом с основной.
- Храните заметки локально или включайте синхронизацию только для выбранных материалов.
- Организуйте библиотеку с помощью групп, поиска, избранного и сортировки.

## Web

- Создавайте и редактируйте многостраничные заметки в браузере.
- Рисуйте, стирайте, выделяйте, перемещайте и меняйте размер объектов.
- Копируйте, вырезайте, вставляйте и отменяйте действия.
- Добавляйте изображения кнопкой или перетаскиванием.
- Просматривайте PDF-заметки, синхронизированные с iPad.
- Отправляйте выделенную задачу ИИ и получайте пошаговое объяснение.
- Размещайте формулы и диаграммы ИИ прямо на холсте.
- Проверяйте черновик решения перед сохранением.
- Используйте историю ИИ-чатов и персональный стиль почерка.
- Отправляйте выбранный фрагмент в приложение AIbook для Windows.

## Windows

- Войдите в тот же аккаунт AIbook.
- Получайте выбранные в web-версии фрагменты в реальном времени.
- Автоматически загружайте пропущенные изображения после восстановления связи.
- Просматривайте полученные изображения и их миниатюры.
- Храните полученные PNG локально на компьютере.
- Смотрите разрешение, размер, дату и путь каждого файла.
