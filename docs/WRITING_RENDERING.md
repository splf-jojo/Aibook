# Writing: вёрстка и диагностика

`/dev/writing` сравнивает исходную вёрстку MathJax с результатом замены
символов на почерк или печатные контуры. Верхнее превью зависит от LaTeX и Size;
Variation, Vertical scatter, Padding и Margin применяются к нижнему результату.

## Рамки

- **Cell** — область размещения символа. Один расчёт используется для верхнего
  превью, почерка и печатного вывода. Обычные символы получают ячейку высотой
  один em относительно базовой линии; индексы масштабируются вместе с шрифтом,
  растягиваемые знаки используют собственные границы. Эти диагностические
  ячейки не задают высоту MathJax и не изменяют расположение дробей и степеней.
- **Glyph** — фактическая рамка размещённой картинки, печатного контура или
  заглушки с её поворотом. Это не синоним Cell.
- **Reference bounds** — рамка, ограничивающая существующее вписывание почерка.
  Его формула масштабирования остаётся прежней; смена Printed не меняет её смысл.
- **Applied padding / margin** — реально применённые значения, с учётом масштаба
  индексов и ограничения padding, оставляющего хотя бы один пиксель внутри Cell.
- Координаты инспектора относятся к формуле до внешнего обрамления SVG.
  Отрицательные значения допустимы. Просмотр рамок добавляет место только
  вокруг изображения в интерфейсе; PNG и размеры самого изображения не меняются.

Для измерений используются контуры отдельных SVG-элементов: браузер может
возвращать разные консервативные `getBBox()` для визуально одинаковых вложенных
групп. Группировка `dx`, `dy`, `sin` и других образцов сохраняется при Printed;
невидимые математические операторы не входят в рамки соседних символов.

## Режимы и настройки

Printed заменяет представление символов, сохраняя выбранный датасет для
группировки. При нулевых четырёх настройках полностью печатный результат
использует исходный SVG MathJax с белым фоном — без повторной сборки контуров.
Так сохраняются также акценты, растянутые знаки и линии таблиц.

В нижнем печатном выводе Padding и Variation преобразуют контуры символов;
Margin меняет естественные метрики MathJax добавлением заданных отступов;
Vertical scatter перемещает целые элементы строки вместе с их индексами.
Структурные части корней и акцентов сохраняются, чтобы не разрушать формулу.
Инспектор явно показывает источник каждого элемента.

Missing symbols — явный выбор между печатной подстановкой и заглушками.
Примеры меняют только входной текст; скрытого режима для отдельных примеров нет.
Text и LaTeX хранят отдельный ввод. Printed относится только к LaTeX.

Непроверенные или неготовые наборы не выдаются за готовый почерк.
Результат привязан к входу, настройкам и версии выбранного набора: при их смене
старый результат недоступен для экспорта, а запоздалые ответы загрузки игнорируются.
Обновление неизменившегося каталога не перезагружает набор.

## Проверка

- `web/tests/handwriting-writing.test.mjs`: padding, margin, текстовая вёрстка,
  алиасы, воспроизводимость вариативности, разброс.
- `web/tests/handwriting-writing.browser.ts`: геометрия реальных SVG, смешанный
  вывод, решения, корни, индексы, прозрачность и снимок почерка для холста.
- `web/tests/handwriting-writing-audit.browser.ts`: общие Cell, точное совпадение
  печатной вёрстки, сложные формулы, отдельные ненулевые настройки, крайние
  значения, границы экспорта, поворот заглушек и некорректные размеры образца.
- `web/tests/handwriting-writing-ui.browser.mjs`: сценарии Playwright CLI с
  временными ответами API, включая позднюю загрузку набора, Retry, неготовый
  набор, пустой каталог, переключение режимов и скачивание PNG.

Браузерные функции запускаются после mount во временной локальной клиентской
странице; её не включают в сборку. Проверки интерфейса используют временные
ответы API в браузере, не создают, не одобряют и не публикуют датасеты.
Нормализация исходных наборов и отдельная обработка iPad Design dataset в эту
правку не входят.
