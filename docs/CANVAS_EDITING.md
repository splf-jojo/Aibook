# Выделение и история редактора заметок

В веб-редакторе инструмент Select содержит два режима:

- **Objects** выбирает целые объекты кликом или прямоугольной рамкой.
- **Under figure** выбирает содержимое прямоугольной области. При перемещении,
  вырезании, удалении или изменении размера обрабатывается только часть каждого
  объекта внутри рамки. Остальное остаётся на месте. Само выделение и Copy
  исходную заметку не меняют.

Меню Select открывается нажатием на его иконку рамки. Выбор режима, повторное
нажатие, Escape или нажатие снаружи закрывают меню, сохраняя выбранный инструмент.
Диагностические границы элементов включаются отдельной кнопкой с гаечным ключом.
По умолчанию ластик работает в объектном режиме; обычный доступен через удержание
кнопки ластика.

Углы рамки меняют размер пропорционально относительно противоположного угла.
Можно масштабировать сразу несколько выбранных объектов. Размер маркеров и зона
нажатия учитывают приближение холста. Перемещение и масштабирование ограничены
текущей страницей; фрагмент можно вырезать и вставить на другую страницу.

## Клавиатура и история

- Ctrl+Z — отмена; Ctrl+Y или Ctrl+Shift+Z — повтор.
- В macOS также поддерживается Cmd вместо Ctrl.
- Ctrl+C / Ctrl+X / Ctrl+V — копирование / вырезание / вставка при активном Select.
- Delete удаляет выделенное; Escape снимает выделение.
- Когда фокус находится в поле ввода или диалоге, команды холста не перехватываются.

История хранит последние 100 операций в пределах открытого редактора. Один жест
рисования, стирания, перемещения или масштабирования — одна операция, включая
рисование с переходом между страницами и добавление следующего листа. В истории
также учитываются фото, вставка, дублирование, удаление и принятие решения ИИ.
Выделение и навигация не очищают Redo; новое изменение очищает его. После выхода
из заметки история начинается заново. Результат Undo/Redo автосохраняется.

Отдельная команда отмены решения ИИ сохраняет своё поведение. При разделении
изображения решения история получает идентификаторы его фрагментов; Undo решения
может убрать оставшиеся и перемещённые части, не затрагивая пользовательские копии.

## Фото из Проводника

PNG и JPEG можно перетащить на нужную страницу. Изображение центрируется в точке
отпускания, вписывается в страницу без изменения пропорций и становится выделенным.
Координаты вычисляются по текущему прямоугольнику именно этой страницы, включая
приближение и прокрутку. Зона страницы подсвечивается при перетаскивании файла.

Несколько файлов вставляются одной операцией с небольшим смещением; один Undo
убирает весь пакет. Проверяются содержимое файла и прежнее ограничение 20 МБ на
изображение. Если хотя бы один файл не удалось прочитать, вся вставка отменяется.
Во время загрузки другие изменения холста заблокированы. Drop за пределами бумаги
не вставляет изображение и не открывает файл вместо приложения. Кнопка добавления
фото использует тот же механизм загрузки и сохраняет вставку по центру страницы.

## Компаньон и оформление чата

На главной странице **Settings → Companion** выбираются `Off`, `White` или
`Teacher` («Выключен», «Белый», «Учитель»). Настройка сохраняется в localStorage
под ключом `canvas_app_companion`; это настройка браузера, а не отдельной заметки.
`White` — исходный персонаж. `Teacher` использует `/companions/teacher.png` и
зелёную доску с рамкой и белым текстом в панели ИИ. Тема холста при этом не меняется.

Персонаж виден в кнопке закрытого чата и в пустом чате. После появления сообщений
или во время ожидания ответа он скрыт. При `Off` персонажа нет и в пустом чате,
а панель открывается обычной кнопкой. Пользовательские сообщения остаются в
облачках, ответы ИИ выводятся прямо на фоне панели. Копирование ответов и ссылки
на решения сохраняются.

## Хранение фрагментов

Формат API не меняется: фрагменты записываются как обычные `image` с прозрачным
PNG, координатами и размерами. Разрезанный объект заменяется непересекающимися
остатками и выбранной частью на прежнем уровне слоёв. Бумага и фон PDF не входят
в выделение. Ошибка загрузки изображения прерывает подготовку операции целиком.

Частично разрезанные текст и штрихи становятся изображениями; они больше не
редактируются как исходные текст/штрихи. Undo возвращает исходные объекты.
Масштабирование целых текста и штрихов сохраняет их тип и меняет размер шрифта
или толщину линии. Старые карточки и звёзды с фиксированной внутренней отрисовкой
при масштабировании преобразуются в изображения.

Захват выполняется отдельно для каждого объекта без бумаги, рамки выделения и
соседних объектов. Разрешение не зависит от приближения холста: для векторного
содержимого используется 2 пикселя на единицу страницы, для фото учитывается
разрешение исходника. Временный растр ограничен 4096 пикселями по большей стороне.
Повторное сильное увеличение растровых фрагментов может снижать чёткость.

## Проверка

Геометрия разрезания, ограничения масштабирования и история:

```powershell
node --test --test-isolation=none web/tests/canvas-editing.test.mjs web/tests/canvas-photo.test.mjs web/tests/canvas-solution-history.test.mjs web/tests/canvas-viewport.test.mjs
```

В браузере проверить половину двухцветного фото: выделение не создаёт Undo,
перемещение оставляет прозрачное место и неподвижный остаток, Undo возвращает
исходник. Повторить для Cut/Paste, изменения размера фрагмента с приближением,
целого текста, штрихов и области, пересекающей несколько объектов. Проверить
ввод в чате, один шаг отмены для длинного жеста, смену страниц и повторное
открытие сохранённой заметки. Для настоящего iPad требуется отдельная проверка
отображения сохранённых PNG-фрагментов на Mac/iPad; Swift-код не меняется.
