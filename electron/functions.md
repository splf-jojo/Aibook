# AIbook for Windows — готовые функции

Этот список описывает основные пользовательские функции, которые реализованы в текущем Windows-клиенте. Windows-версия сейчас служит приёмником фрагментов холста, отправленных из web-версии AIbook.

## Аккаунт

- Вход в существующий аккаунт AIbook.
- Безопасное сохранение сессии между запусками приложения.
- Проверка сохранённой сессии при запуске и возврат к экрану входа, если она истекла.
- Выход из аккаунта с очисткой локальной сессии.

## Получение изображений

- Автоматическое получение выделенного фрагмента, отправленного из web-холста командой «Отправить на Windows».
- Получение новых изображений в реальном времени через постоянное соединение с сервером.
- Автоматическое переподключение после временной потери связи.
- Загрузка пропущенных изображений после входа или восстановления соединения.
- Подтверждение серверу успешного получения изображения.
- Разделение локальных изображений по аккаунтам.

## Локальная галерея

- Автоматическое сохранение полученных PNG на компьютере.
- Восстановление ранее полученных изображений после перезапуска приложения.
- Галерея миниатюр с выбором изображения.
- Крупный просмотр выбранного изображения.
- Просмотр метаданных: имя файла, формат, разрешение, размер, дата получения и локальный путь.

## Текущая роль платформы

- Windows-клиент не является редактором заметок и не изменяет полученное изображение.
- Создание холста, выделение области и отправка выполняются в web-версии.
- ИИ-чат и решение задач находятся в web- и iPad-версиях, а не в этом клиенте.
